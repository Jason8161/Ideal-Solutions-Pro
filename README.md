# Ideal Solutions

Monorepo for **Ideal Solutions Pro** — contractor field-services software.

| Package | Description |
|---------|-------------|
| [my-app/](my-app/) | Expo / React Native mobile app (iOS, Android, optional web) |
| [pricing-backend/](pricing-backend/) | Express API, pricing search, customer pay & service-request pages |
| [website/](website/) | Marketing site (Astro) — home, features, pricing, docs, blog |

## Marketing website

The public marketing site lives in **[website/](website/)** at **https://www.idealsolutionspro.com**. See [website/README.md](website/README.md) for local dev, Formspree setup, and Cloudflare Pages deployment.

```bash
cd website
npm install
npm run dev
```
