HOW TO RESTORE ON THIS PC OR ANOTHER DEVICE

  2. Unzip the backup so that package.json and the app folder end up inside my-app
     (the zip has paths like "app\..." at the root — extract "into" the my-app folder so my-app\package.json exists)
  3. Open a terminal in my-app and run:
       npm install
  4. Start as usual, e.g.  npx expo start
